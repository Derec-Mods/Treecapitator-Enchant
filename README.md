Enchant for axes that veinmines entire trees at once, taking into account enchants and durability. Helps with mass resource gathering on big survival worlds!

This has been in mods for as long as mods have been a thing! A lot of datapacks add this idea, as well as mods, and I wanted to implement it in an optimized plugin form, with the recent release of Paper API's https://docs.papermc.io/paper/dev/lifecycle/datapacks/

**To repeat**, as of latest updates, this plugin now requires PaperMC. If you've been running a survival server, you should have switched to PaperMC/Purpur/any other fork of it ALREADY, to improve your server performance. You should NOT be running Spigot or a Vanilla server in 2026. 

_This was created for use on my forever world, called "derex smp". Check it out in action, server ip: `mc.longhorns.dev`_

## Features
- Logging enchant for axes
- Super lightweight tree breaking algorithm
- Automatic conversion / compatibility with Veinminer enchant 
- Anti-Griefing features to prevent players from accidentally breaking houses and builds that use logs
- Compatibility with CoreProtect and other grief / block logging mods and plugins
